## 6. How sure can we be? What review samples support

**A. Missed differences.** The expert re-checks a random sample of items the system marked "no difference". If none turn out to be a missed difference, the true miss rate is below the bound shown, with 95% confidence (exact one-sided bound; the 'rule of three' gives about 3/n).

| Items re-checked, 0 misses found | 95% upper bound on miss rate |
|---:|---:|
| 50 | 5.8% |
| 100 | 3.0% |
| 150 | 2.0% |
| 200 | 1.5% |
| 300 | 1.0% |
| 500 | 0.6% |

**B. Recall on the gold set.** If the system finds 90% of the known differences in the gold set, the true recall lies in this 95% interval (Wilson). Small gold sets give wide intervals, which is why the gold set needs enough real differences.

| Known differences in gold set | Observed recall | 95% interval |
|---:|---:|---|
| 20 | 90% | 70% – 97% |
| 40 | 90% | 77% – 96% |
| 60 | 90% | 80% – 95% |
| 100 | 90% | 83% – 94% |
| 200 | 90% | 85% – 93% |

**C. Reviewer agreement.** Classification (for example, is this rule *stricter*, or just *different*?) is a judgement call. A second reviewer should label a subset of about 50–100 findings blind, so that agreement can be reported (for example, Cohen's kappa).
